# Enhanced Todo List

A simple Todo List application with the following features:-

- Add tasks to a list
- Mark tasks as completed
- Remove tasks
- Search tasks in real time
- Persist tasks using `localStorage`

## How to Use the to do filr

1. Open `index.html` in the browser.
2. Type a task in the input box and click "Add Task".
3. Click a task to mark it as completed.
4. Click the "Delete" button to remove a task.
5. Use the search bar to filter tasks in real time.
6. open developers tools>application>local storage.
7. Tasks are saved in browser's `localStorage` and will persist on reload.
