🌟 Responsive Personal Portfolio Website

This project is a responsive personal portfolio webpage built using HTML + CSS only, following the assignment requirements.
I used an AI tool to generate the initial layout and then manually improved the design, structure, and responsiveness.

🚀 Features
✔ Fully Responsive (Mobile, Tablet, Desktop)

Desktop → Navigation in a row

Tablet → Text reflows, skills grid becomes 2-columns

Mobile → Stacked navigation, 1-column skills, no horizontal scroll

✔ Clean & Modern Design

Simple color theme

Smooth layout spacing

Easy-to-read typography

✔ Sections Included

Header with name + navigation

Hero with headline, description, and Contact Me button

Skills Section (6+ skills)

Footer with social media links

🤖 AI Tool Used

Replit AI was used to generate the initial basic template.
After generating the code, I moved everything to VS Code and made significant manual improvements.
